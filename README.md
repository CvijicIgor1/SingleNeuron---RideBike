# SingleNeuron---RideBike
Python Program za odredjivanje da li treba voziti Bicikl tog dana
Koriscena je biblioteka numpy ( https://numpy.org/ ) , potrebno je instalirati pomenutu datoteku ( pip install numpy )

Postoje dva fajla:

Optimizovana_Voznja.py gde je izbacena for petlja koja radi po slicnom principu kao i funkcija .dot i dodat je "feature" gde je na osnovu pokretanja drugaciji output zbog bias-a

Voznja_Bicikla.py je testni slucaj
